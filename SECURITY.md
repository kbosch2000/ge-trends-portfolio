# Security policy

Please do not publish connection tokens, authentication material, or a working
exploit in a public issue.

Report security concerns privately to `karim.bosch@hotmail.com` with:

- a description of the issue;
- reproduction steps;
- the affected plugin or website version; and
- the potential impact.

Connection tokens are portfolio-ingestion credentials only. A potentially
exposed token should be replaced immediately from the GE Trends account page.
